# Retail Returns Copilot UI

Guided-tour SPA for the Retail Returns Copilot demo. Vite + React + TypeScript, styled with
Tailwind CSS and shadcn/ui, animated with Framer Motion.

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and produce a production build
npm run lint     # oxlint
npm run format   # prettier --write
npm test         # vitest
```

Currently ships Stage 1 of the guided tour ("meet the stack") -- a static illustration of the
agent/MCP/gateway/registry topology. See the design doc in the `agentic-field-kit` repo for the
full guided-tour plan.
